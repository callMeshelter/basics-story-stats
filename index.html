Basics Story stats

Basics Story stats is a private tool used only by the owner of the YouTube channel Basics Story. It reads the channel's own YouTube statistics (views, watch time, audience retention, traffic sources) through the YouTube Data API and the YouTube Analytics API, so the channel owner can see which videos work best.

The tool has read-only access. It cannot upload, edit or delete anything on YouTube, and it is not offered to other users.
